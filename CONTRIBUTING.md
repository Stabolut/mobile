# Contributing to Stabolut Mobile

Thank you for contributing to the Stabolut Mobile Wallet app!

## Getting Started

1. Fork the repo and create a feature branch:
   `ash
   git checkout -b feature/my-new-feature
   `
2. Install dependencies:
   `ash
   npm install
   `
3. Test your changes in Android/iOS emulators.
4. Open a Pull Request with a clear explanation of the changes made.
